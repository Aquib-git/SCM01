Smart Contact Manager Application

Overview

The Smart Contact Manager is an intuitive web-based application designed to efficiently organize, manage, and 
streamline your personal and professional contacts. Built using modern technologies, 
it offers an interactive user interface and secure data management capabilities.

Features

User-friendly Interface: Easily manage contacts through an intuitive interface.

CRUD Operations: Seamlessly create, read, update, and delete contact information.

Advanced Search and Filters: Find contacts using built-in search and filter functionalities.

Secure Storage: Contacts are stored securely with data privacy and integrity in mind.

Responsive Design: Optimized for use across multiple devices (desktop, tablet, mobile).

Technologies Used

Frontend: HTML5, CSS3, JavaScript, React.js

Backend: Java, Spring Boot, Spring MVC

Database: MySQL/Oracle Database

Frameworks & Tools: Git, Maven, Spring Security, Bootstrap, REST APIs

Installation & Setup

Prerequisites:

Java (JDK 11 or higher)

Maven

MySQL/Oracle DB

Git

Steps:

Clone the repository:

git clone https://github.com/YourUsername/smart-contact-manager.git

Navigate to the project directory:

cd smart-contact-manager

Configure Database:

Set your database configuration in application.properties.

Build and Run:

mvn clean install
mvn spring-boot:run

Access the application:

Navigate to http://localhost:8080

Usage

Register/Login to your account.

Start adding and managing your contacts efficiently through the provided interface.
